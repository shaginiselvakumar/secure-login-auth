STEP 1: Create a new repository on GitHub
─────────────────────────────────────────
Go to: https://github.com/new

Repository name: secure-login-auth
Description: Secure authentication system with login, signup, password reset, and MFA
Visibility: Public (or Private)

⚠️ DO NOT check "Initialize with README" - we already have one!

Click "Create repository"


STEP 2: Copy these commands and run them
─────────────────────────────────────────
Replace YOUR-USERNAME and YOUR-REPO-NAME with your actual values!

cd "LOGIN AUTH"
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
git branch -M main
git push -u origin main


EXAMPLE (if your username is "shagini" and repo is "secure-login-auth"):
─────────────────────────────────────────────────────────────────────────
cd "LOGIN AUTH"
git remote add origin https://github.com/shagini/secure-login-auth.git
git branch -M main
git push -u origin main


AUTHENTICATION
─────────────────────────────────────────
When prompted:
- Username: Your GitHub username
- Password: Use a Personal Access Token (NOT your GitHub password!)

To create a token:
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Select scope: "repo"
4. Copy the token
5. Use it as your password when pushing


VERIFY UPLOAD
─────────────────────────────────────────
After pushing, check:
✅ All files are on GitHub
✅ .env file is NOT there (only .env.example should be visible)
✅ README.md displays nicely


FUTURE UPDATES
─────────────────────────────────────────
To push changes later:

git add .
git commit -m "Your commit message"
git push
